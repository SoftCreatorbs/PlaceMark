A taxa é descontada do valor sacado: o vendedor pede R$ 100,00 e recebe R$ 100,00 menos a taxa. O prazo de liberação protege contra estornos e contestações de cartão depois do repasse.

Envio automático: o que precisa

  1. Use o Access Token da conta da Placemark em Admin → Mercado Pago (o mesmo que recebe as vendas).
  2. Peça ao Mercado Pago a liberação da API de Saques / Money Out (Pix) para a sua aplicação.
  3. Em produção, o Mercado Pago exige que cada envio seja assinado com chaves que eles fornecem. Até isso estar configurado, os envios recusados caem na fila manual, sem perder nada.
  4. Mantenha saldo na conta Mercado Pago: vendas no cartão podem levar dias para ficar disponíveis lá. Se faltar saldo, o saque volta para a fila.

Proteções: cada saque tem uma chave única, então reenviar nunca paga duas vezes. O Pix só é aceito para uma chave do mesmo CPF/CNPJ da conta Mercado Pago que o vendedor conectou. {% if teste %}Modo teste ativo.{% endif %}
